# 💡 Important Coaching Note

* The biggest resume mistake is listing duties instead of **business impact**.
* Weak bullet:
  > Responsible for managing social media accounts.
* Strong bullet:
  > Managed **5 social media channels**, increasing engagement **38%** in **6 months** through data-driven content planning.
